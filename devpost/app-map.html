ConceptLens AI · code map

From a wrong answer to a concept to review

The app turns one topic into an explanation, an explorable concept map, and a three-question quiz. A wrong answer names and highlights the map concept it tested.

One connected learning flow

A three-stop reference route

Follow this route in the editor to see how one answer reaches the highlighted concept.

  1. src/components/QuizPanel.tsx

    Start at QuizQuestionView. It renders the selected option's reasoning, the correct-answer explanation, and the separate review pointer.

  2. src/App.tsx

    Follow answerQuestion. A wrong answer adds that question's nodeId to the in-session review IDs.

  3. src/components/ConceptMap.tsx

    In MapCanvas, the same ID sets the amber marker and requests a pan to the reviewed node.

To change this, start here

server/src/services/gemini.ts, createInteractionWithRetries: change the lesson instructions sent to Gemini.

shared/generateSchema.ts, QuizQuestionSchema: change the shared question contract and its structured-output guidance.

server/src/services/validateResponse.ts, validateGenerateResponse: change structural and question-to-map link checks.

src/components/QuizPanel.tsx: change the feedback wording or its scrollable layout.

A practice to reuse

When generated data refers to another record by ID, validate both that the ID exists and, with a real response, that it names the concept the question actually tests. Here, schema validation checks the shape and the server checks the link; the live review caught a question incorrectly linked to the root topic, so the prompt was tightened and the live flow was run again.

Run the app again

From the repository root, run npm run dev, then open http://localhost:5173. Gemini mode requires local values in server/.env; follow the setup notes in README.md.
